# Словарь терминов проекта pr-diz.ru

Цель этого документа — фиксировать решения по названиям **по мере того, как они возникают**,
а не переименовывать что-то задним числом. Когда дойдём до отдельного пункта плана
("Пересмотр наименований"), у нас уже будет обдуманный список, а не пустой лист.

## Как этим пользоваться

- **Новый код** — сверяемся со словарём, используем уже принятые термины.
- **Новый термин возникает впервые** — обсуждаем, вносим сюда, потом используем.
- **Существующее название режет слух, но трогать его прямо сейчас рискованно** — вносим
  в раздел "Кандидаты на будущее переименование" с пометкой, где оно встречается, чтобы
  не потерять мысль, но не переименовываем в отрыве от остального кода.

## Статусы

- ✅ **Принято** — используется в новом коде.
- 🕓 **Кандидат** — существующее название, которое стоит поменять при большом проходе
  по наименованиям (пункт 5 плана), но не трогаем прямо сейчас.

## Принятые термины

| Термин (код, англ.) | Значение (рус.) | Где используется / появился | Статус |
|---|---|---|---|
| `external` (например, `externalRolls`, `externalTotals`) | "Постороннего происхождения" — не результат данного технологического процесса, а добавленное к нему извне | `CalculationRolls`: рулоны, добавленные к отгрузке, но не являющиеся результатом резки данного заказа (в БД — таблица `calculation_not_take_stream`) | ✅ |
| `shipment` | Отгрузка (юридический документ — акт-отчёт о передаче данных по отгрузке) | Новый раздел `shipment/`, таблица `shipment` | ✅ |
| `shipment_calculation` | Связь заказов с отгрузками ("многие ко многим") | Таблица-связка; записи только добавляются, никогда не редактируются/не удаляются — тот же принцип, что и у остальных `*_history`-таблиц | ✅ |
| `document_number` | Номер товарной накладной | Поле `shipment.document_number` — не просто `document`, потому что это именно номер, а не сам документ | ✅ |
| `vehicle_number` | Гос. номер транспортного средства | Поле `shipment.vehicle_number` — аналогично, не `vehicle` | ✅ |
| `cargo_type` | Наименование груза (плёнка / упаковка / этикетка) | Поле `shipment.cargo_type`; значения — PHP-константы `CARGO_TYPE_*`, как и другие подобные небольшие фиксированные наборы в проекте (`ORDER_STATUS_*`, `WORK_TYPE_*`), а не отдельная таблица-справочник | ✅ |
| `places_count` | Количество мест (грузовых) | Поле `shipment.places_count` | ✅ |
| `is_draft` / `draft_reason` / `draft_at` / `draft_by` | Механизм "перевода в черновики" — необратимая пометка недействительности юридического документа, вместо редактирования/удаления | Поля `shipment.*` | ✅ |

## Кандидаты на будущее переименование

| Текущее название | Проблема | Где встречается | Заметки |
|---|---|---|---|
| `calculation` / `Calculation*` (классы, таблица) | Изначально означало "расчёт стоимости", но объект давно стал полноценным "заказом" — название вводит в заблуждение | Таблица `calculation`, классы `CalculationBase`, `CalculationResult`, `CalculationRolls`, папка `calculation/` и т.д. — используется почти во всём проекте | Самое масштабное потенциальное переименование в проекте — требует отдельного, аккуратного прохода |
